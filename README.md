# sk-not-book-pre

Gelişmiş not alma uygulaması

## Özellikler

- Kullanıcı oturum sistemi
- Not kategorizasyonu
- Arama ve filtreleme
- Dark/Light tema desteği
- PWA desteği

## Kurulum

1. Projeyi klonlayın
2. `npm install` komutunu çalıştırın
3. Firebase projesini oluşturun ve yapılandırma dosyasını güncelleyin
4. `npm run dev` ile geliştirme modunda çalıştırın

## Firebase Kurulumu

1. [Firebase Console](https://console.firebase.google.com/) adresine gidin
2. Yeni proje oluşturun
3. Web uygulamasını ekleyin
4. Firebase yapılandırma bilgilerini `src/core/firebase/firebaseConfig.js` dosyasına ekleyin
